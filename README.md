# Nakshatra - CampusChain

Welcome to the **Team GoofyGeek's** project repository. The primary application is located in the `campus-chain` directory.

## 🚀 CampusChain
### The Blockchain-Powered University Financial Ecosystem

**CampusChain** is a decentralized platform designed to unify fragmented university payment systems using **Account Abstraction (ERC-4337)** and **Soulbound Tokens (SBTs)** made for round 1 of Nakshatra Hackathon.

### 📁 Project Structure
- [campus-chain](file:///d:/fintech-nakshatra/campus-chain): Main Next.js application, including frontend, business logic, and UI.
- [implementation_plan.md](file:///d:/fintech-nakshatra/implementation_plan.md): Detailed architectural design and roadmap.

### 🏁 Quick Start
To get started with the project, navigate to the `campus-chain` directory and follow the instructions in its [README](file:///d:/fintech-nakshatra/campus-chain/README.md).

```bash
cd campus-chain
npm install
npm run dev
```
